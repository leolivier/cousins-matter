## Was ist Cousins Matter?
Cousins Matter ist eine Webanwendung, die Ihnen bei der Verwaltung großer Stammbäume hilft. Sie können Ihre Cousins und Cousinen, Tanten und Onkel, Geschwister, Kinder und Vorfahren auflisten und ihnen die Möglichkeit geben, ihre eigenen Profile zu verwalten. Die Anwendung bietet zudem verschiedene nützliche Funktionen wie:

* Fotogalerien,
* Foren,
* Chaträume,
* Umfragen
* Kleinanzeigen
* Stammbäume,
* OAuth/SSO-Authentifizierung (Google, Facebook, GitHub, PocketID usw.)
* ...

Sie kann auch zur Verwaltung kleiner Gemeinschaften (d. h. mit nicht mehr als ein paar hundert Personen) eingesetzt werden, z. B. von Sport- oder Spieleclubs.

Zum Betrieb dieser Anwendung benötigen Sie einen kleinen Server, auf dem eine aktuelle Version von Docker installiert ist. Dies kann ein Raspberry Pi 4 oder 5, ein alter PC oder ein kleiner virtueller privater Server (VPS) sein. Die Anwendung läuft auf 2 vCPUs und 2 GB RAM problemlos; die Festplattengröße ist nur für die Speicherung von Fotos wichtig (und künftig noch mehr für Videos).

Diese Website enthält die gesamte Dokumentation zur Installation und Verwaltung der Anwendung.

## Migration von Version 1 auf Version 2
Die Version 2 von Cousins Matter ist eine umfassende Neuentwicklung der Version 1. Sie ist nicht direkt mit der Version 1 kompatibel. Um von Version 1 auf Version 2 zu migrieren, folgen Sie bitte den Anweisungen auf der Seite [Migration von Cousins Matter von v1 auf v2](migrate-from-v1-to-v2.md).
