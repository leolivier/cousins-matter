
# ![Cousins Matter!](assets/logo.webp) COUSINS MATTER!

## O que é o Cousins Matter?
O Cousins Matter é uma aplicação web concebida para o ajudar a gerir grandes árvores genealógicas. Permite-lhe listar os seus primos, tias, tios, irmãos, filhos e antepassados, e dá-lhes a possibilidade de gerir os seus próprios perfis. A aplicação também oferece várias funcionalidades úteis, tais como:

* galerias de fotos,
* fóruns,
* salas de conversa,
* sondagens,
* anúncios classificados,
* árvores genealógicas,
* autenticação OAuth/SSO (Google, Facebook, GitHub, PocketID, etc.)
* ...

Também pode ser utilizada para gerir pequenas comunidades (ou seja, não mais do que algumas centenas de pessoas), como clubes desportivos ou clubes de jogos.

Para executar esta aplicação, precisará de um pequeno servidor no qual esteja instalada uma versão recente do Docker. Pode ser um Raspberry Pi 4 ou 5, um PC antigo ou um pequeno servidor virtual privado (VPS). A aplicação funcionará confortavelmente com 2 vCPU e 2 GB de RAM, sendo o tamanho do disco apenas importante para o armazenamento das fotos (e, num futuro próximo, ainda mais para os vídeos).

Este sítio contém toda a documentação relativa à instalação e à gestão da aplicação.

## Migrar da versão 1 para a versão 2
A versão 2 do Cousins Matter é uma grande reescrita da versão 1 e não é diretamente compatível com a versão 1. Para migrar da versão 1 para a versão 2, siga as instruções da página [migração da versão 1 para a versão 2 do Cousins Matter](migrate-from-v1-to-v2.md).
